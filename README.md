# demo-fujitec

Delphi クライアント/サーバー型の業務システムを、Devin で Web アプリ（Vue.js + Java Spring Boot + PostgreSQL）へ移行するデモです。

## 構成

| パス | 内容 |
|---|---|
| `legacy/` | 移行元。公開リポジトリ [MDsolucoesTI/Pegasus](https://github.com/MDsolucoesTI/Pegasus)（MIT ライセンス）の在庫管理システム。Delphi 5/6、DB は Paradox。 |

移行元のコードは原作者の MIT ライセンス（`legacy/LICENSE`）に従って取り込んでいます。原本の README は `legacy/README.original.md` です。
